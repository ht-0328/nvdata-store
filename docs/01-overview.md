# 地方競馬DATA の全体像

**地方競馬DATA は、地方競馬（NAR）の出馬表・成績・オッズ・マスタを配信する有料サービスです。**
JRA-VAN Data Lab. が中央競馬に対して果たしている役割を、地方競馬に対して果たします。
運営は株式会社インター通信社（競馬最強の法則WEB）で、月額約2,000円の契約で利用キーが発行されます。

データは **UmaConn** というソフトを通してだけ受け取れます。UmaConn の中身は **NV-Link** という COM コンポーネントで、
JRA-VAN の JV-Link とそっくりの呼び方をします。配信されるデータの形も JV-Data を踏襲しています。
**JV-Data を知っていれば、違いだけ覚えれば読めます。** このページでは全体像と、JV-Data との違いの要点を押さえます。

## 使うまでに要るもの

| 要るもの | 何か | 確かめ方 |
| :--- | :--- | :--- |
| 地方競馬DATA の契約 | 月額の会員登録。利用キーが発行される | 会員ページ |
| UmaConn | NV-Link（`C:\Windows\SysWOW64\NVDTLab.dll`、32bit）と設定画面 `UmaConn設定.exe` | レジストリに ProgID `NVDTLabLib.NVLink` が登録される |
| 利用キーの登録 | 設定画面にキーを入れる。`NVSetUIProperties` で開ける | `m_servicekey` に値が入る |
| 32bit で動く呼び出し側 | NV-Link は 32bit の部品なので、64bit のプロセスからは作れない | [NV-Link の呼び方](05-nvlink-interface.md) |

受け取ったデータは `C:\UmaConn\chiho.k-ba\data\` の下に保存されます（通常データは `cache\<年>\`、セットアップは `data\<年>\`）。

## 覚える言葉は JV-Data と同じ3つです

| 言葉 | 例 | 何を指すか | 誰が使うか |
| :--- | :--- | :--- | :--- |
| **データ種別ID** | `RACE` `DIFN` `0B30` | **取得の単位。** 「レース情報をくれ」と頼むときの名前 | `NVOpen` / `NVRTOpen` に渡す |
| **レコード種別ID** | `RA` `SE` `NU` `HA` | **中身の型。** 1レコードが何の情報かを示す名前 | レコードの先頭2バイト |
| **ファイル** | `RANV2026100320261003231018.nvd` | 配信の物理単位。複数レコードが入る | 意識しなくてよい |

ファイル名は「レコード種別ID ＋ `NV` ＋ 開催日8桁 ＋ 作成日時14桁 ＋ `.nvd`」で、**1日1レコード種別につき1ファイル**です。
中身は zip 圧縮されていて、そのままでは読めません。`NVGets` がファイルの区切りを隠して1本の列にしてくれるので、依存しないでください。

## JV-Data との違いの要点

**同じところ**: 固定長レコード、文字コード（Shift_JIS / cp932）、先頭3項目（レコード種別ID・データ区分・データ作成年月日）、
レースの鍵（開催年・月日・競馬場コード・回・日目・レース番号）、`RA` `SE` `H1` `H6` `O1`〜`O6` `BN` `CH` `KS` `WH` `WE` `AV` の並び。

**違うところ**は4つに分けられます。

| 違い | 何が | どこに書いてあるか |
| :--- | :--- | :--- |
| 地方だけのレコードがある | `NU` 競走馬、`NK` 騎手、`NC` 調教師、`NN` 馬主、`NB` 生産者、`ND` 出走別着度数、`HA` `OA` 枠単の票数とオッズ | [レコード索引](reference/index.md) |
| 同じ ID でも中身が違うものがある | `HR` 払戻（予備の位置に枠単）、`WF` 重勝式（3レースの馬単、組番が16進） | [HR](reference/HR.md) / [WF](reference/WF.md) |
| 届かないレコードがある | 調教（`HC` `WC`）、血統（`HN` `SK` `BT`）、マイニング予想（`DM` `TM`）、開催スケジュール（`YS`）、特別登録（`TK`）など | [データ種別と提供範囲](03-dataspecs.md) |
| コード値と表し方が違う | 競馬場コード `83`（ばんえい帯広）、グレードコード `P`〜`T`、ばんえいの負担重量と馬体重が16進 など | [地方特有のコード値](reference/codes.md) / [レコードの読み方](02-record-format.md) |

> [!NOTE]
> **ばんえい競馬も入っています**
>
> 帯広のばんえい競馬は競馬場コード `83`、トラックコード `90`、距離 `0200`、品種コード `B` で配信されます。
> 負担重量（そり）と馬体重は3桁に収まらないので、**16進で書かれています**。読む側で場合分けが要ります。

## 蓄積系と速報系

JV-Data と同じ区分です。提供期間は確かめられた範囲だけを書きます。

| | 蓄積系 | 速報系 |
| :--- | :--- | :--- |
| 何のためか | 過去のデータを貯める | 当日の変化を追う |
| 呼び出し | `NVOpen` | `NVRTOpen` |
| 指定するもの | 読み出し開始時刻（いつ以降か） | キー（どの日か／どのレースか） |
| データ種別IDの形 | `RACE` `DIFN` `DIFF` `SNAP` | `0B11` `0B30` `0B41` など |
| 遡れる範囲 | **セットアップで2005年1月1日まで**。通常データは3か月前の指定で取れた。それより前の保持期間は未確認 | 前日分は取れた。何日前まで取れるかは未確認 |
| 1日あたりの単位 | 1レコード種別につき1ファイル | キーごと |

くわしくは [データ種別と提供範囲](03-dataspecs.md) にあります。

## 何が届くか（ひとことで）

| 分類 | 届くもの | データ種別ID |
| :--- | :--- | :--- |
| レース | 出馬表・成績（`RA` `SE`）、払戻（`HR`）、票数（`H1` `H6` `HA`）、確定オッズ（`O1`〜`O6` `OA`）、重勝式（`WF`） | `RACE` |
| マスタ | 競走馬（`NU`）、騎手（`KS` と `NK`）、調教師（`CH` と `NC`）、馬主（`BN` と `NN`）、生産者（`NB`） | `DIFN` / `DIFF` |
| 出走時点 | 出走別着度数（`ND`） | `SNAP` |
| 速報 | 馬体重（`WH`）、天候馬場状態・取消（`WE` `AV`）、出馬表と成績（`RA` `SE` `HR`）、オッズ（`O1`〜`O6` `OA`）、時系列オッズ（`O1` `O2`）、重勝式（`WF`） | `0B11` `0B14` `0B12` `0B15` `0B30`〜`0B36` `0B41` `0B42` `0B51` |

騎手・調教師・馬主は、JV-Data と同じ形（`KS` `CH` `BN`）と地方の形（`NK` `NC` `NN`）の**両方**が届きます。
同じコードの人物が両方に入っていて、地方の成績（競馬場別・距離別の着回数）を持っているのは地方の形のほうです。
