# レコードのつながり

**表をどう結合するか**をまとめます。鍵の考え方は JV-Data と同じで、地方特有の落とし穴が3つあります。

## 鍵の一覧

| 鍵 | 桁 | 使うレコード |
| :--- | ---: | :--- |
| レースキー（開催年・開催月日・競馬場コード・開催回・開催日目・レース番号） | 16 | `RA` `SE` `HR` `H1` `H6` `O1`〜`O6` `HA` `OA` `ND` |
| 血統登録番号 | 10 | `NU` `SE` `ND` |
| 騎手コード | 5 | `NK` `KS` `SE` `ND` |
| 調教師コード | 5 | `NC` `CH` `NU` `SE` `ND` |
| 馬主コード（＋馬主名） | 6（＋64） | `NN` `BN` `NU` `ND` |
| 生産者コード（＋生産者名） | 6 または 8（＋70 または 72） | `NB` `NU` `ND` |
| 開催年・開催月日 | 8 | `WF`（対象レースは中に3つ入っている） |

## つながり

```
RA レース詳細 ──レースキー──┬─ SE 馬毎レース情報 ──血統登録番号── NU 競走馬マスタ地方
                           │        ├─ 騎手コード ── NK 騎手マスタ地方（KS も同じコード）
                           │        └─ 調教師コード ── NC 調教師マスタ地方（CH も同じコード）
                           ├─ HR 払戻 / H1 H6 HA 票数 / O1〜O6 OA 確定オッズ
                           └─ ND 出走別着度数地方 ──血統登録番号── NU
NU ── 馬主コード＋馬主名 ── NN 馬主マスタ地方（BN も同じコード）
NU ── 生産者コード＋生産者名 ── NB 生産者マスタ地方
WF 重勝式 ── 対象レース情報（競馬場・回・日目・レース番号）×3 ── RA
```

## 落とし穴

### 1. 馬主コード・生産者コードの `000000`

地方の馬主の約半数、生産者の約3分の2がコード `000000` です。**コードだけで結合すると別人が混ざります。**
`NN` と `NB` の1件を決める鍵は「コード＋名前（法人格無）」で、`NU` `ND` から引くときも、コードが `000000` なら名前で引きます。
`NU` の馬主名・生産者名は「法人格無」なので、`NN` `NB` の 法人格無 の列と合わせてください。

### 2. 騎手・調教師・馬主は2つの表に同じ人がいる

`KS` と `NK`、`CH` と `NC`、`BN` と `NN` は、**同じコードの同じ人物**が JV-Data の形と地方の形で両方届きます。
基本の属性（名前・生年月日・所属）はどちらにもあり、**競馬場別・距離別の着回数は地方の形（`NK` `NC` `NN`）だけが持ちます。**
地方の成績を見るなら地方の形を使い、JV-Data 向けの既存の SQL を流用するなら JV-Data の形を使う、という使い分けになります。
両方を貯める必要はありません。

### 3. 繁殖馬マスタが無い

`NU` の3代血統情報には繁殖登録番号（10桁）と馬名が並びますが、**繁殖馬マスタ（`HN`）は届きません。**
父母の名前は `NU` の中にあるものを使います。中央の繁殖馬マスタ（JV-Data の `HN`）と同じ番号体系なので、
中央のデータを持っていればそちらで引けます。ばんえいは3代目より先の馬名が空です。

## 中央との行き来

- `SE` の東西所属コードが `1`（美浦）`2`（栗東）の馬は、中央所属馬の地方交流競走への出走です。その馬のマスタ（`UM`）は地方競馬DATA では届かないので、JV-Data 側で引きます。
- 中央の `RA` `SE` にも 2000年以降の中央交流競走と、中央に出走した地方馬の過去走が入っています（JV-Data仕様書 4.9.0.1 p.31）。
  同じレースが両方にあるときは、競馬場コードが同じ（`30`〜`57`）なので鍵が一致します。
- ばんえい（`83`）は中央側にはありません。

## 時系列オッズの鍵

`0B41` `0B42` で届く `O1` `O2` と、`OA` には **発表月日時分** があり、同じレースに複数の断面が来ます。
貯めるときはレースキーに発表月日時分を足して1行にします（jvdata-store と同じ方針）。確定オッズ（`RACE` で届くもの）はレースキーだけで1件です。
