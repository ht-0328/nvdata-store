## JV-Data の CK との違い

CK（6,870バイト）の中央向けの区分を、地方向けに置き換えたものが ND です。

- 賞金は平地の3項目だけ（障害の項目がない）。
- 馬の着回数は **総合・地方合計・回り6・馬場状態8・距離22（芝11＋ダ11）・競馬場38（芝5＋ダ33）** の76組（3桁×6）。
- 騎手・調教師の 本年･累計成績情報は 1,220 → **1,524 バイト**。中身は 設定年・本賞金合計・付加賞金合計・
  芝着回数（5桁×6）・ダート着回数（5桁×6）・距離22区分（4桁×6）・競馬場38区分（4桁×6）。
- 馬主・生産者の 本年･累計成績情報（60バイト）は CK と同じ形。
- 生産者コードは 6 バイト、生産者名は 70 バイトの旧サイズ（SNAP でだけ届くため）。

## 確かめ方

- 項目名とバイト数は PC-KEIBA テーブル定義書の `nvd_nd` から取った。定義書は生産者を新サイズ（8・72）で書いているが、
  実データのレコード長 8,179 に合うのは旧サイズなので、こちらを採った。
- 騎手・調教師の成績情報 1,524 バイトの内訳は実データから読み解いた。32,123 件すべてで
  **芝着回数＋ダート着回数 ＝ 距離22区分の和 ＝ 競馬場38区分の和**、**芝着回数 ＝ 芝距離11区分の和 ＝ 芝5場の和** が成り立つ。
- 競馬場38区分の並びは、レースの競馬場と成績の最多の競馬場が一致すること（14場すべて）で確かめた。
- 調教師の成績情報では、本賞金合計が観測した範囲ですべて 0 だった。
