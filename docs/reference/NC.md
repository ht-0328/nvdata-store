## JV-Data の CH との違い

CH（3,862バイト）の **本年･前年･累計成績情報が 1,052 → 1,464 バイト**になったものが NC です。
成績情報の中身は [NK](NK.md) と同じ（全場合計 ＋ 地方33場 ＋ 距離6区分）。それ以外の項目は CH と同じ位置です。

## 確かめ方

- 項目名とバイト数は PC-KEIBA テーブル定義書の `nvd_nc` から取り、合計がレコード長 5,098 と一致することを確かめた。
- 本年の成績情報 7,363 件で、合計着回数 ＝ 33場の和 が 7,363 件すべて、合計着回数 ＝ 距離6区分の和 が 7,298 件で成り立つ。
