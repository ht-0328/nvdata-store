## JV-Data の UM との違い

UM（1,609バイト）から障害に関する項目（障害本賞金累計・障害付加賞金累計・障害収得賞金累計・
障害・着回数・障良〜障不・着回数、合わせて117バイト）を抜いたものが NU です。残った項目の位置は、
その分だけ前にずれます。項目の意味も次の点が違います。

| 位置 | NU | UM |
| ---: | :--- | :--- |
| 179 | 在厩フラグ | JRA施設在きゅうフラグ |
| 1,071 | 地方合計着回数 | 中央合計着回数 |
| 1,053〜 | 本賞金累計・付加賞金累計・収得賞金累計（平地のみ） | 平地と障害が交互に並ぶ6項目 |

DIFF（旧種別）で届く NU は 1,460 バイトで、繁殖登録番号が 8 バイト、生産者コードが 6 バイト、
生産者名が 70 バイトです。本ドキュメントは DIFN（新種別）の形を載せています。
DIFF の NU は血統登録番号の体系も違う（同じ馬に別の番号が付いている）ので、混ぜないでください。

## 確かめ方

- 項目名とバイト数は PC-KEIBA テーブル定義書の `nvd_nu` から取り、合計が実データのレコード長 1,492 と一致することを確かめた。
- DIFN で届いた 32,033 件のうち 3,000 件を読み、日付の項目が yyyymmdd、コードの項目がコード表の値、
  着回数が3桁×6の数字になっていることを確かめた。
- 血統登録番号の先頭4桁は、サラブレッド（品種 1・2）では生年月日の年と一致する。ばんえい（品種 B）は一致しない。
