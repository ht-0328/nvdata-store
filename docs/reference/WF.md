## JV-Data の WF との違い

長さは同じ 7,215 バイトですが、次の点が違います。

- 位置 20 の予備2バイトのうち、後ろの1バイトが **式別コード** です。観測した範囲では `1` だけで、
  **3レースの馬単を順に当てる重勝式**（いわゆるトリプル馬単）を指します。対象レースは5つの枠のうち3つだけ使い、残りは 00 埋めです。
- 重勝式払戻情報の **組番（10バイト）は16進表記**です。10進に直すと、「1着馬番2桁＋2着馬番2桁」を対象レースの順に並べた
  12桁の数になります。例: `0997E40C8D` → `041203010701` → 1レース目 4-12、2レース目 3-1、3レース目 7-1。
  JV-Data（WIN5）の組番は10進10桁なので、そのまま読むと別の値になります。

ほかの項目は JV-Data の WF と同じです。全項目は [jvdata-store の WF のページ](https://ht-0328.github.io/jvdata-store/reference/WF/) を見てください。

## 確かめ方

- 3か月分 115 件（門別・浦和・船橋・大井・川崎）の組番を、同じ日の対象レースの1着・2着の馬番（SE）と突き合わせ、
  16進→10進の読み方で5件すべてが一致することを確かめた。
