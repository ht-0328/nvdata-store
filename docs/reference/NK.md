## JV-Data の KS との違い

KS（4,173バイト）に次を足したものが NK です。

- 所属調教師名略称 の直後に **服色標示（画像取得用）・服色標示（文字表示用）**（60バイト×2）が入る。
- **本年･前年･累計成績情報が 1,052 → 1,464 バイト**になる。中身は中央10場の平地・障害ではなく、
  **全場合計 ＋ 地方33場 ＋ 距離6区分**（いずれも6桁×6）で、障害の項目はない。賞金は本賞金合計と付加賞金合計の2つ。

33場の並びは固定で、廃止された競馬場も枠だけ残っています。
門別・北見・岩見沢・帯広・旭川・盛岡・水沢・上山・三条・足利・宇都宮・高崎・浦和・船橋・大井・川崎・
金沢・笠松・名古屋・紀三井寺・園田・姫路・益田・福山・高知・佐賀・荒尾・中津・札幌・函館・新潟・中京・春木。
帯広はばんえいの成績が入ります。

## 確かめ方

- 項目名とバイト数は PC-KEIBA テーブル定義書の `nvd_nk` から取り、合計がレコード長 5,529 と一致することを確かめた。
  定義書は成績情報を 1,464 バイトの塊としか書いていないので、中身は実データから読み解いた。
- 本年の成績情報 5,379 件で、合計着回数 ＝ 33場の和 が 5,378 件、合計着回数 ＝ 距離6区分の和 が 5,326 件で成り立つ
  （残りはばんえいなど、距離区分に入らない競走とみられる）。
- 33場の並びは、値の入る場所が今ある15場（門別・帯広・盛岡・水沢・浦和・船橋・大井・川崎・金沢・笠松・名古屋・園田・姫路・高知・佐賀）
  にだけ現れることと、騎手ごとの今年の騎乗数（SE）と矛盾しないことで確かめた。盛岡と水沢は騎乗数の比較で順を確かめた。
