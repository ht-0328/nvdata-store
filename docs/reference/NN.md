## JV-Data の BN との違い

BN（477バイト）に次を足したものが NN です。

- 服色標示 の直後に **服色標示 ホッカイドウ（画像取得用）・服色標示 ホッカイドウ（文字表示用）**（60バイト×2）が入る。
- **本年･累計成績情報が 60 → 116 バイト**になる。中身は KS の成績情報の頭と同じ形
  （設定年・平地本賞金・障害本賞金・平地付加賞金・障害付加賞金・平地着回数・障害着回数）。

## 鍵について

**馬主コードが `000000` の馬主が、観測した 19,210 件のうち 9,000 件近くあります。** 馬主コードだけでは1件が決まらないので、
馬主名(法人格無) と合わせて鍵にします（PC-KEIBA も同じ扱い）。NU や SE から馬主を引くときも、コードが `000000` なら名前で引いてください。

## 確かめ方

- 項目名とバイト数は PC-KEIBA テーブル定義書の `nvd_nn` から取り、合計がレコード長 709 と一致することを確かめた。
- 成績情報 116 バイトの内訳は、値の入る位置（設定年の4桁、先頭の賞金10桁、44バイト目からの6桁×6）から読み解いた。
