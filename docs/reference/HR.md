# HR — 払戻

| | |
| :--- | :--- |
| レコード種別ID | `HR` |
| レコード長 | 719 バイト |
| 項目数 | 52 |
| 届くデータ種別 | `RACE` `0B12` `0B15` |

## キー

この組み合わせで1件が決まります。

1. 開催年
2. 開催月日
3. 競馬場コード
4. 開催回[第N回]
5. 開催日目[N日目]
6. レース番号

## JV-Data の HR との違い

長さは同じ 719 バイトですが、JV-Data で予備になっている4か所に **枠単** が入ります。

| 位置 | JV-Data | NV-Data |
| ---: | :--- | :--- |
| 37 | 予備（不成立フラグの並びの中） | 不成立フラグ　枠単 |
| 46 | 予備（特払フラグの並びの中） | 特払フラグ　枠単 |
| 55 | 予備（返還フラグの並びの中） | 返還フラグ　枠単 |
| 406〜453 | 予備 16バイト×3 | 枠単払戻（組番2＋払戻金9＋人気順2）×3 ＋ 予備 9 |

ほかの項目は JV-Data の HR と同じです。全項目は [jvdata-store の HR のページ](https://ht-0328.github.io/jvdata-store/reference/HR/) を見てください。
枠単を発売しないレースでは、枠単の項目は 0 と空白です。

## 確かめ方

- 3か月分 4,220 件で、返還フラグ　枠単 に 1 が 40 件入り、枠単払戻の組番が枠番の組（例 7-8）、払戻金が9桁、人気順が2桁で読めることを確かめた。
- 不成立フラグ・特払フラグの枠単は観測した範囲ではすべて 0。
