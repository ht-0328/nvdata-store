# OA — オッズA（枠単）

| | |
| :--- | :--- |
| レコード種別ID | `OA` |
| レコード長 | 693 バイト |
| 項目数 | 16 |
| 届くデータ種別 | `RACE` `0B30` |

## キー

この組み合わせで1件が決まります。

1. 開催年
2. 開催月日
3. 競馬場コード
4. 開催回[第N回]
5. 開催日目[N日目]
6. レース番号

## どこで届くか

[HA](HA.md) と同じく、枠単を発売する競馬場のレースにだけ付きます。
RACE の確定オッズのほか、速報オッズ 0B30 にも入ってきます（O1〜O6 の後ろ）。

## JV-Data の O1〜O6 との対応

1組が **組番(2)＋オッズ(6)＋人気順(2)** の 10 バイトで、オッズの桁は O4（馬単）と同じ 0.1倍単位の6桁です。
データ区分は O1 などと同じで、観測した範囲では 5（確定）と 9（中止）。

## 確かめ方

- 項目名とバイト数は PC-KEIBA テーブル定義書の `nvd_oa` から取り、合計がレコード長 693 と一致することを確かめた。
- 943 件すべてで組番が 11,12,…,18,21,…,88 の順に並び、オッズと人気順が数字か空白か '-' 埋めになっていることを確かめた。
