# 地方特有のコード値

JV-Data のコード表（JV-Data仕様書 4.9.0.1「コード表」）にない値と、地方で意味が広がっている値をまとめます。
JV-Data にある値は [jvdata-store のコード表](https://ht-0328.github.io/jvdata-store/reference/codes/) を見てください。

**出どころはすべて実データ**（2026年7月〜10月、レース詳細 8,488 件・馬毎レース情報 86,319 件・マスタ約11万件）です。
意味を書いた箇所は、周りの項目（競走条件名称・重賞回次・競馬場・競走名）から読み取った**推定**で、
提供元の定義ではありません。「不明」と書いた値は、意味を決める手がかりがありませんでした。

## 2001.競馬場コード {: #2001 }

地方競馬場は JV-Data と同じ `30`〜`57`（廃止場を含む）。**ばんえい帯広だけ JV-Data にない値**です。

| 値 | 意味 | 観測 |
| :--- | :--- | :--- |
| `83` | ばんえい帯広 | レース詳細 996 件。すべてトラックコード `90`、距離 `0200`、品種コード `B` |

観測した期間に開催があった競馬場: `30` 門別 `35` 盛岡 `36` 水沢 `42` 浦和 `43` 船橋 `44` 大井 `45` 川崎 `46` 金沢 `47` 笠松
`48` 名古屋 `50` 園田 `54` 高知 `55` 佐賀 `83` ばんえい帯広。姫路（`51`）は開催が無く、マスタの着回数にだけ現れます。

## 2003.グレードコード {: #2003 }

| 値 | JV-Data の意味 | 地方での意味（推定） | 根拠 |
| :--- | :--- | :--- | :--- |
| `A` `B` `C` | G1 G2 G3 | ダートグレード競走 JpnI JpnII JpnIII | 副題が「農林水産大臣賞典」、重賞回次あり。帝王賞が `A`、日本テレビ盃が `B`、マーキュリーカップが `C` |
| `E` | 重賞以外の特別競走 | 同じ（特別競走） | 933 件のうち重賞回次ありは 13 件 |
| `P` | （無し） | 主催者の格付け I の重賞（南関東 SI、東海 SPI など） | 8 件すべて重賞回次あり |
| `Q` | （無し） | 格付け II の重賞（南関東 SII、ホッカイドウ H2、ばんえい BG2 など） | 14 件すべて重賞回次あり |
| `R` | （無し） | 格付け III の重賞 | 17 件すべて重賞回次あり |
| `S` | （無し） | 格付けのない重賞（岩手・金沢・兵庫・高知・佐賀 など） | 42 件すべて重賞回次あり |
| `T` | （無し） | 準重賞 | 33 件のうち重賞回次ありは 3 件 |
| 空白 | （未設定） | 一般競走 | |

`D`（グレードのない重賞）と `L`（リステッド）は観測していません。

## 2005.競走種別コード {: #2005 }

| 値 | JV-Data の意味 | 地方での意味（推定） | 根拠 |
| :--- | :--- | :--- | :--- |
| `11` `12` `13` `14` | サラ系 2歳 / 3歳 / 3歳以上 / 4歳以上 | 同じ | 競走条件名称が「２歳」「３歳」「３歳上…」「４歳上…」 |
| `49` | （無し） | **年齢条件のない競走**（格付け別の条件戦 など） | 競走条件名称が「Ｃ４－２」「Ｃ１」のように年齢を持たない。地方のレースの半数がこの値 |
| `01` | （無し） | ばんえい 2歳 | 競走条件名称「２歳　Ｄ－２」など。ばんえいのみ |
| `02` | （無し） | ばんえい 3歳 | 「３歳　ＯＰ」 |
| `03` | （無し） | ばんえい 4歳 | 「４歳　ＯＰ」 |
| `04` | （無し） | ばんえい 年齢混合（条件戦） | 「Ｃ２－１ … 220.0万未満」など。ばんえいで最多 |
| `06` | （無し） | ばんえい 5歳 | 「５歳　ＯＰ」 |
| `08` | （無し） | ばんえい 3・4歳 | 「3・4歳ＯＰ」 |

競走条件コード（2歳〜5歳以上・最若年）は、地方では**すべて `000`** でした。条件は 競走条件名称 の文字列で読みます。

## 2006.競走記号コード {: #2006 }

JV-Data は3桁の数字ですが、地方では**英字が入ります**。意味は不明です。観測した値: `000` `001` `00A` `010` `020` `021` `030`
`0A0` `0A1` `0B0` `0B1` `C00` `M00` `M01` `X00` `X20` `XA0` `Y00`。
`000` が 7,666 件で、ばんえいは `020` `030` が多く、`X00` は門別が多い、という偏りがあります。

## 2009.トラックコード {: #2009 }

| 値 | 意味 | 観測 |
| :--- | :--- | :--- |
| `90` | ばんえい（JV-Data に無い） | 競馬場コード `83` のみ |
| `11` `23` `24` `26` | 芝・直線 / ダート・左 / ダート・右 / ダート・右外（JV-Data と同じ） | `11` は盛岡の芝 |

## 2010.馬場状態コード {: #2010 }

ダート馬場状態コードに、**ばんえいだけ** JV-Data にない値が入ります。

| 値 | 観測 | 意味 |
| :--- | :--- | :--- |
| `0`〜`4` | 全場 | 未設定 / 良 / 稍重 / 重 / 不良（JV-Data と同じ） |
| `5`〜`9` `A`〜`F` | ばんえい帯広のみ | 不明。ばんえいは馬場状態を**馬場水分（%）**で発表するので、その区分とみられる。PC-KEIBA の定義書も、ばんえいの着回数の良〜不良を馬場水分の区分（0.0〜0.9%、1.0〜1.9%、…）と注記している |

## 2011.天候コード {: #2011 }

`0`（未設定）が出馬表の段階（データ区分 `2`）で入ります。確定後は `1`〜`4`（晴・曇・雨・小雨）。`5` `6`（雪・小雪）は観測していません。

## 2201.品種コード {: #2201 }

| 値 | 意味 | 観測 |
| :--- | :--- | :--- |
| `B` | ばんえい（JV-Data に無い） | 競馬場コード `83` の全出走馬と、競走馬マスタ地方の約1割 |
| `1` `2` | サラブレッド / サラブレッド系種 | ほか全部 |

## 2301.東西所属コード {: #2301 }

地方所属は `3`。`1`（美浦）`2`（栗東）は交流競走に出た中央馬。`0` は騎手マスタ地方・調教師マスタ地方で招待地域名が空の人に付いています。

## データ区分

レコードごとの使われ方は [レコードの読み方](../02-record-format.md) の「違うところ 1」にまとめました。

## 数値の表し方

| 項目 | どこで | 表し方 |
| :--- | :--- | :--- |
| 負担重量・馬体重（`SE`） | ばんえい（競馬場コード `83`）のみ | **16進**。`26C` → 620、`41B` → 1,051 |
| 重勝式払戻情報の組番（`WF`） | 全場 | **16進**。10進に直すと「1着馬番2桁＋2着馬番2桁」×3レースの12桁 |
| 発売のない組（`O1` `O6` `H1` など） | 全場 | `*` 埋め。取消は JV-Data と同じ `-` 埋め |
