# 地方競馬DATA（NV-Data）の読み方

地方競馬DATA が **UmaConn（NV-Link）** 経由で配信する地方競馬のデータの仕様を、
実際に受け取ったデータで確かめながらまとめたものです。

**地方競馬DATA には、公開された開発者向けの仕様書がありません。** ここでは、次の3つを突き合わせて仕様を起こしています。

| 資料 | 何に使ったか |
| :--- | :--- |
| JV-Data仕様書 4.9.0.1（JRA-VAN Data Lab. SDK 同梱） | 地方競馬DATA は JV-Data の形を踏襲している。同じレコードの項目の並びと意味 |
| PC-KEIBA テーブル定義書（地方競馬DATA に対応したソフトの DB 定義） | 地方だけのレコードの項目名とバイト数 |
| UmaConn で実際に受け取ったデータ（2026年7月〜10月） | レコード長・並び・値の範囲。合計と内訳の整合で並びを確かめた |

## このドキュメントの立場

**公式の仕様書ではありません。** 項目名とバイト数は PC-KEIBA テーブル定義書から取り、並びと意味は実データで確かめました。
確かめ方は各レコードのページの末尾に書いてあります。推定にとどまる箇所は「推定」と書いています。
実データは 2026年7月〜10月の3か月分なので、その期間に現れなかった値や、年に一度しか変わらないものは確かめられていません。
