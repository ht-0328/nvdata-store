# データ種別と提供範囲

**何を頼めば何が届くか、どこまで遡れるか**をまとめます。すべて UmaConn 3.5.4 で実際に開いて確かめた結果です。
戻り値の意味は JV-Link と同じ（`0` 成功、`-1` 該当データ無し、`-111` データ種別が不正、`-116` データ種別と option の組み合わせが不正）。

## 蓄積系（NVOpen）

### 開けるデータ種別

| データ種別ID | 戻り値 | 届くレコード | 中身 |
| :--- | :--- | :--- | :--- |
| `RACE` | `0` | `RA` `SE` `HR` `H1` `H6` `O1`〜`O6` `HA` `OA` `WF` | レース情報。出馬表・成績・払戻・票数・確定オッズ・枠単・重勝式 |
| `DIFN` | `0` | `BN` `CH` `KS` `NC` `NK` `NN` `NU` | マスタ（新サイズ）。競走馬は地方の形 `NU` だけ |
| `DIFF` | `0` | `BN` `CH` `KS` `NB` `NC` `NK` `NN` `NU` | マスタ（旧サイズ）。生産者マスタ地方 `NB` はここにしかない |
| `SNAP` | `0` | `ND` | 出走別着度数地方 |
| `BLDN` `BLOD` `SLOP` `YSCH` `HOSE` `HOYU` `COMM` `TOKU` | `-1` | — | 種別としては受け付けるが、該当データ無し |
| `SNPN` | `-116` | — | 新種別の出走別着度数は無い。`SNAP` を使う |
| `MING` `WOOD` `HOSN` `TCVN` `RCVN` | `-111` | — | 種別として存在しない |

つまり**使うのは `RACE` `DIFN` `SNAP` の3つ、生産者マスタ地方が要るなら `DIFF` も**です。

> [!CAUTION]
> **`DIFF` と `DIFN` の `NU` は混ぜない**
>
> 同じ `NU` でも `DIFN` は 1,492 バイト、`DIFF` は 1,460 バイトで、繁殖登録番号・生産者コード・生産者名の桁が違います。
> さらに血統登録番号の体系が違い、同じ馬に別の番号が付いています。マスタは `DIFN` から取り、`DIFF` は `NB` を取る目的だけに使ってください。

### 3か月でどれだけ届くか

2026年7月1日以降の通常データを開いたときの件数です。設計の目安にしてください。

| データ種別ID | ファイル数 | レコード | 件数 |
| :--- | ---: | :--- | ---: |
| `RACE` | 1,290 | `RA` 8,488 / `SE` 86,319 / `HR` 4,220 / `H1` `O1`〜`O6` 各 4,236 / `H6` 4,236 / `HA` `OA` 各 943 / `WF` 115 | 134,916 |
| `DIFN`（9月1日以降） | 238 | `NU` 32,033 / `NN` 19,210 / `NC` 7,370 / `NK` 5,383 / `CH` 7,184 / `KS` 5,217 / `BN` 19,210 | 95,607 |
| `DIFF`（9月1日以降） | 272 | 上に `NB` 12,437 が加わる | 108,044 |
| `SNAP`（9月1日以降） | 34 | `ND` 16,070 | 16,070 |

`RA` は出馬表（データ区分 2）と確定（7）で同じレースが2回届くので、レース数は約 4,200 です。
マスタは毎日のファイルに「その日に更新された行」が入り、同じ人物が何度も届きます。

### セットアップ（option 4）で遡れる範囲

**地方競馬DATA のデータは 2005年1月1日からです。** セットアップで読み出し開始時刻を指定したときの対象ファイル数です（`RACE`）。

| 読み出し開始時刻 | 対象ファイル数 |
| :--- | ---: |
| 1990年・2000年・2003年・2005年 | 96,302（同じ。2005年より前を指定しても 2005年から） |
| 2008年 | 86,083 |
| 2010年 | 79,171 |
| 2015年 | 56,091 |
| 2020年 | 31,700 |
| 2025年 | 8,405 |

1日1レコード種別につき1ファイルなので、年間 8,000〜9,000 ファイルになります。

> [!IMPORTANT]
> **読み出し終了時刻は効きません**
>
> JV-Link の `JVOpen` は `20050101000000-20060101000000` の形で終わりを指定できますが、
> NV-Link は終わりの部分を無視します。2005年〜2006年を指定しても 96,302 ファイル（2005年から現在まで）が対象になりました。
> **セットアップを年ごとに区切って取ることはできません。** 一度に開いて、ダウンロードの完了を待ちながら読むことになります。

オッズ・票数は 2010年2月以降しかない、という情報が外部にあります（本ドキュメントでは未確認）。

通常データ（option 1）は、3か月前（2026年7月1日）を指定して取れました。それより前の保持期間は確かめていません。
JV-Link と同じ運用（初回はセットアップ、2回目以降は前回の最終ファイル時刻から続き）で貯められます。

## 速報系（NVRTOpen）

キーは JV-Link と同じ2種類です。開催日単位は `YYYYMMDD`、レース単位は `YYYYMMDDJJKKHHRR`（開催年月日＋競馬場コード＋回＋日目＋レース番号）。

| データ種別ID | キー | 戻り値 | 届くレコード | 中身 |
| :--- | :--- | :--- | :--- | :--- |
| `0B11` | 開催日 | `0` | `WH` | 馬体重 |
| `0B12` | 開催日 | `0` | `RA` `SE` `HR` | 成績（確定したレースぶん） |
| `0B14` | 開催日 | `0` | `WE` `AV` | 天候馬場状態・出走取消。騎手変更 `JC`・発走時刻変更 `TC` が出る可能性はあるが、観測した日には無かった |
| `0B15` | 開催日 | `0` | `RA` `SE` `HR` | 出馬表と成績 |
| `0B51` | 開催日 | `0` | `WF` | 重勝式 |
| `0B30` | レース | `0` | `O1` `O2` `O3` `O4` `O5` `O6` （枠単発売場は `OA` も） | オッズ（全賭式） |
| `0B31`〜`0B36` | レース | `0` | `O1` / `O2` / `O3` / `O4` / `O5` / `O6` | オッズ（賭式ごと） |
| `0B41` | レース | `0` | `O1` × 断面数 | 時系列オッズ（単複枠）。1レースで 58〜126 断面が届いた |
| `0B42` | レース | `0` | `O2` × 断面数 | 時系列オッズ（馬連） |
| `0B13` | 開催日 | `-1` | — | マイニング予想は無い |
| `0B16` `0B17` `0B43`〜`0B46` | — | `-111` | — | 種別として存在しない |
| `0B20` | 開催日 | `-114` | — | キーの形が違うとみられる（未解明） |

速報の `RA` `SE` `HR` `WH` `WE` `AV` `O1`〜`O6` `OA` `WF` は、蓄積系と同じレコード長・同じ並びです。

前日（2026年10月4日）の速報は、翌日に取れました。何日前まで取れるか（JV-Link は1週間）は確かめていません。

## 保存先とファイル

NV-Link は受け取ったファイルを `m_savepath`（既定 `C:\UmaConn\chiho.k-ba\data\`）の下に残します。

| 置き場所 | 何が入るか |
| :--- | :--- |
| `cache\<年>\` | 通常データ・速報 |
| `data\<年>\` | セットアップデータ |

ファイル名は `RANV2026100320261003231018.nvd` のように「レコード種別ID（2）＋ `NV` ＋ 開催日（8）＋ 作成日時（14）＋ `.nvd`」です。
中身は zip 圧縮で、`NVGets` を通して読みます。マスタのファイルは `NUWV…` のように3〜4文字目が `WV` です。

## 使い分けの指針

| したいこと | 使うもの |
| :--- | :--- |
| 過去のレース・成績・払戻・確定オッズを貯める | `RACE` をセットアップで一度に取り、以後は続きから |
| 競走馬・騎手・調教師・馬主のマスタ | `DIFN`（新サイズ）。地方の成績を持つのは `NU` `NK` `NC` `NN` |
| 生産者マスタ地方 | `DIFF` の `NB` だけを使う |
| 出走別着度数 | `SNAP` の `ND` |
| 当日の馬体重・天候・取消・オッズ | `0B11` `0B14` `0B30`（レースごと） |
| 締め切り前のオッズの動き | `0B41`（単複枠）`0B42`（馬連）。3連単などの時系列は無い |
